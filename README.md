# 函数作图器（2D / 3D）

纯前端、无后端依赖的函数作图工具：输入 z(x,y) 作三维曲面，输入 y(x) 作二维曲线。
支持旋转缩放、坐标轴刻度、悬停显示坐标、多函数叠加对比、自定义颜色、计算求值、历史快照与 PNG 导出。

## 快速开始

- **单文件版**：直接双击打开 函数作图器.html（所有依赖已内联，离线可用，可单独拷贝分享）。
- **开发版**：保持 index.html + lib/ + src/ 目录结构，直接打开或用任意静态服务器均可。

## 输入格式

| 类型 | 示例 | 视图 |
| --- | --- | --- |
| 二元函数（三维曲面） | z(x,y)=x^2+y^2 | 三维 |
| 一元函数（二维曲线） | y(x)=sin(x) | 二维 |

- 必须写成 名称(变量表)=表达式 的形式；**变量名可自定义**（如 f(u,v)=u*sin(v)），坐标轴会随声明的变量名显示。
- 添加一元函数自动切换到二维视图，添加二元函数自动切换到三维视图；两类函数可共存，视图顶部标签页切换。
- 多个函数叠加显示，图例在视图右上角（点击图例项可临时隐藏对应函数）。

## 表达式语法

- 运算：+ - * / ^、括号；支持隐式乘法（2x、2sin(x)）。
- 常用函数：sin cos tan asin acos atan sinh cosh tanh ln log log10 exp sqrt abs floor ceil round sign atan2 min max 等（mathjs 全量函数可用）。
- 内置常数：pi、e、tau、phi。
- **常数字母**：表达式中未被声明的字母自动识别为常数参数，显示在函数卡片中可实时调节，如 f(x)=a*x^2+b。
- 注意：xy 会被当作一个整体符号，相乘请写 x*y；sqrt(-1) 等复数/无穷结果按“无定义”处理（该区域不绘制）。

## 交互说明

- 三维视图：左键旋转、滚轮缩放、右键平移；鼠标悬停曲面时显示该点三维坐标（变量名随输入自动变化）。
- 二维视图：滚轮以光标为中心缩放、拖拽平移、双击复位；悬停自动吸附最近曲线并显示坐标。
- 计算求值：选择函数 → 输入变量值（支持 pi/2 这类表达式）→ 计算；“标注到图”会在对应视图画出该点。
- 历史记录：一键保存当前全部函数与视图配置为快照，随时载入/删除（浏览器本地存储，重启不丢）。
- 导出 PNG：按当前视图导出图片。

## 自定义颜色

- 每个函数：面/线颜色、不透明度、显隐、三维线框开关。
- 三维视图：背景、x/y/z 轴、网格、刻度文字颜色；采样密度 20–140。
- 二维视图：背景、x/y 轴、网格、文字颜色。

## 开发与构建

~~~bash
node tests/math-core.test.mjs   # 表达式解析核心测试（15 项）
node build.mjs                  # 重新生成单文件版 函数作图器.html
node --check src/app.js         # 语法检查
~~~
