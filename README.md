# 函数作图器

一个纯前端的数学可视化工具：函数作图、隐函数/隐式曲面、几何构造、微积分、线性代数参考系变换。
零框架、零后端——最终产物是**一个自包含的 HTML 文件**，双击即可使用，也可直接托管到任意静态网站。

> 由「二元函数作图」项目演化而来，功能上吸收并重构了 mathflow 的算法与交互设计。

## 功能总览

### 函数作图
- **二维曲线**：`y(x)=sin(x)`、`x(y)=y^2/2`（横向曲线）、符号形式 `y=…`
- **隐函数（等值线）**：直接输入 `x^2+y^2=1`、`sin(x)=cos(y)`，Marching Squares 自动提取曲线
- **三维曲面**：`z(x,y)=sin(x)*cos(y)`，逐像素采样 + Lambert 光照 + 可选线框
- **隐式曲面**：`x^2+y^2+z^2=1`、`x^2+y^2=(z-1)^2` 等，按列扫描 z 求交生成网格
- **常数参数**：表达式里未声明的字母自动识别为常数（如 `y=a*x^2+b`），带
  - 数字框 + 滑杆（-5~5）双通道调节
  - ▶ 参数动画（-5~1 往复 yoyo）
- **模板库**：33 个函数模板（幂/三角/指数对数/双曲/分段感觉/特殊/参数族）+ 7 个曲面示例，一键添加

### 几何构造（二维）
- 工具：**选择 (V)** / **平移 (H 或右键拖拽)** / **加点** / **画线** / **画圆**
- 点可拖拽，线段与圆实时跟随（依赖联动）
- 删除自动级联（删点 → 依赖它的线/圆一并删除）
- 属性检查器：点坐标可编辑；线段长度/斜率/中点；圆半径/周长/面积
- 两点拾取有虚线预览；`P1/L1/C1` 自动编号

### 微积分
- **符号求导**：mathjs `derivative`，结果直接作为新曲线加入
- **定积分**：上下限支持表达式（`pi/2`、`sqrt(2)`）与无穷（`inf` / `-inf`）
- **反常积分**：变量代换 + Simpson 复合法则（n=80）
- **变上限积分**：上限写变量（如 `x`）→ 生成可绘制的 `F(x)` 曲线
- 特殊源码可直接输入并持久化：`calculus(sin(t), t, 0, x)`、`dcalculus(x^2, x)`

### 线性代数 / 参考系变换
- **2×2 / 3×3 矩阵**编辑，实时显示行列式/迹/特征值/变换类型
- 预设：恒等、旋转 30°、剪切、缩放、反射、投影（2D）；绕 X/Y/Z 旋转等（3D）
- **Follow Basis**：网格、坐标轴、刻度随矩阵变换呈像
- **非线性变换**：`x'`、`y'`（`z'`）表达式自由定义，支持变量 `x,y,z,t`
- **t 参数动画**：非线性场随时间流动
- **应用到点**：把线性变换烘焙进几何点坐标
- 性能：表达式编译结果按源码缓存，动画逐帧只做求值（无逐点重编译）

### 通用
- 视图：滚轮缩放（指针为中心）、拖拽平移、双击复位、悬停吸附提示、图例点击隐藏
- 三维：OrbitControls 环绕、自动 z 范围、隐函数密度/曲面采样密度可调
- 颜色：背景/坐标轴/网格/文字全部可自定义（2D 与 3D 独立）
- 计算求值：任意点函数值 + 一键图上标注（2D/3D 联动）
- 历史快照：保存/载入/删除，最多 50 份
- 导出：当前视图一键导出 PNG
- 持久化：函数、视图、几何、变换自动保存（localStorage），旧版本数据自动迁移

## 使用

无需构建，直接打开 `函数作图器.html` 即可。

> 托管到网站时把它改名为 `index.html` 即可（本项目刻意不预设文件名）。

## 构建单文件

```bash
node build.mjs
```

`build.mjs` 把 `lib/` 与 `src/` 全部内联进一个 HTML（自动校验内联数量与外部引用为零）。

## 开发

源码按职责拆分（浏览器全局 IIFE + Node 可 require 的 UMD）：

| 文件 | 职责 |
| --- | --- |
| `lib/math.min.js` `lib/three.min.js` `lib/OrbitControls.js` | 第三方库（mathjs 11.8 / three r147） |
| `src/math-core.js` | 表达式解析：曲线（y/x/隐函数）、曲面（显式/隐式）、方程形态判定 |
| `src/marching.js` | Marching Squares 等值线、隐式曲面 z 扫描与高度场网格 |
| `src/calculus.js` | Simpson 积分、反常/变限积分、`calculus()`/`dcalculus()` 特型编译 |
| `src/linalg.js` | 2×2/3×3 矩阵运算、特征值、预设、类型判定 |
| `src/templates.js` | 函数/曲面模板库 |
| `src/geometry.js` | 几何对象模型：依赖级联、命中测试、属性计算、序列化 |
| `src/state.js` | 共享状态、函数模型、持久化（含 v1 迁移）、常数动画引擎 |
| `src/view2d.js` | 二维 Canvas 渲染与交互（含参考系变换） |
| `src/view3d.js` | 三维 three.js 渲染（曲面/隐式曲面/变换轴架） |
| `src/app.js` | UI 编排：函数卡、模板面板、几何工具、微积分/线性代数面板、历史、导出 |
